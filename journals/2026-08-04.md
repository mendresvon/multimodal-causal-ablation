## 3. Experimental Execution & Parameters
To execute the ablation sweep efficiently without reloading the raw dataset and massive modality encoders (ALBERT, MTCNN, etc.), I designed a "proxy inference" loop. I loaded the 1152-d `test_feature` tensors directly from the cached SHAP data, split out the 1024-d Text CLS token, injected dataset-mean clamp values for the top-k neurons, and fed the modified vectors straight into `MME2E`'s pre-trained classification heads (`t_out`, `v_out`, `a_out`, `weighted_fusion`). I swept $k \in \{1, 3, 5, 10\}$.

## 4. Empirical Findings & Data Links
The results at $k=5$ (primary target for Tables VII/VIII) showed almost zero accuracy drop across the board. 
- **Base Model:** Only `surprise` proved causally selective (4.17% target drop, 0.0% non-target drop). All other classes exhibited 0.00% target accuracy drop.
- **Fine-tuned Model:** 0.00% target accuracy drop across all 6 emotion classes. The model completely failed the causal selectivity threshold.

## 5. Roadblocks, Failure Modes & Debugging Log
- **Missing Dependencies:** The Colab runtime threw a `ModuleNotFoundError` for `facenet_pytorch`. I resolved this by adding a `!pip install` cell at the top of the notebook referencing the pinned `requirements.txt` and `transformers`.
- **Logic Bug in Selectivity Threshold:** My initial Python logic for the ADR 0001 threshold was `target_drop >= 2.5 * mean_nt_drop`. Because both values were exactly 0.0 for many classes, Python evaluated `0.0 >= 0.0` as `True`, generating false positives. I corrected the inequality to explicitly require `target_drop > 0`.

## 6. Interpretability Retrospective
The data is fascinating. Clamping the 5 most "class-selective" neurons (based on pure activation ratios) out of the 1024-d representation caused effectively zero change in model behavior. This strongly indicates that the network relies on highly distributed, entangled representations (Substrate Dispersion) rather than sparse, human-interpretable "grandmother neurons." Fine-tuning pushes this dispersion even further, completely wiping out the single causally selective set (`surprise`) that existed in the base model.
