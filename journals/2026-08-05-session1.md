## 5. Roadblocks, Failure Modes & Debugging Log
I identified two severe execution flaws that invalidated the run:
1. **Ablation Target Error:** Inside the `ablate_and_evaluate` proxy inference loop, the code explicitly clamped `text_cls[:, n] = dataset_mean_acts[n]` rather than the Audio `specs` tensor.
2. **Kernel Caching Desync:** The Colab notebook relied on a memory check (`if 'base_acts_tier1' not in globals()`) to skip the expensive 30-minute Phase A forward passes. I did not restart the kernel after fixing the code, so the environment skipped loading the new 64-d Audio variables from disk. It fed the stale 1024-d Text tensors, still resident in RAM from a previous session, into the probes and ablation loops.

## 6. Interpretability Retrospective
Stateful execution environments will hide a bug like this indefinitely. The in-memory cache mismatch produced arithmetic that was internally consistent and methodologically wrong, and nothing in the output flagged it, the tables looked like ordinary null results. What caught it was a dimension check I could do by eye: the Audio branch has 64 neurons, so a probe returning index 1010 cannot be reading Audio. Architectural bounds are worth asserting in code for exactly this reason, and I should have had that assert in place before the run rather than after.
