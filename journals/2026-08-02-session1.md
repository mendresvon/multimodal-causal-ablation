## 5. Roadblocks, Failure Modes & Debugging Log
- **Architectural Error (Late Fusion):** An urgent report clarified that MME2E takes a weighted sum of the 6-class classification scores. There is no intermediate "post-fusion representation" vector.
- **Overfitting Trap:** Initially fitting the L1 probe on the entire test set generated 1.000 AUCs. I diagnosed this as the curse of dimensionality and corrected it using cross-validation.
- **Anomalous Activation Shape & The Wrong Dataset Bug:** The precomputed `base_acts.npy` and `base_labels.npy` loaded with 288 samples and 512 dimensions. Tracing the provenance back through the handover hard drive, the RML test split (`Final_test_split_six_categories_RML.txt`) contains 144 samples, which is the shape in my SHAP pickles `(144, 1152)`. Neither the sample count nor the dimension matches, so the 288-sample cache came from a different dataset — IEMOCAP is the likely candidate — and the 512-d flattened shape suggests a different modality branch as well.

## 6. Interpretability Retrospective
The first conclusion — that Tier 1 signal validation failed — was wrong, and it was wrong because of the data cache rather than the method. The probe was scoring 288 samples of 512-d activations from the wrong dataset.

Auditing `e2e.py` settled the architecture question: the Text branch has no intermediate FFN, so the 1024-d ALBERT CLS token goes straight into the final linear classifier and that vector is the Tier 1 representation.

With the inputs corrected — 1024-d features pulled from the cached SHAP pickles (`test_feature[:, 0:1024]`) and the 144 labels parsed from the local `RML_RAW_PROCESSED_Face` metadata (`meta.pkl`) — both probes clear the 0.65 AUC threshold. The Layer Fallback condition in ADR 0001 is therefore not triggered.

One result I did not expect: the base model (Mean AUC 0.7358) carries a stronger text-only signal than the fine-tuned model (0.6771). The gap is concentrated in one class — Anger drops from 0.7368 to 0.5342. The reading I favour is that multimodal fine-tuning moved the model's reliance for anger off text and onto audio or video, which is the transfer effect this study is meant to quantify. I want to hold that loosely: a probe AUC gap is correlational, one class is a thin basis, and I have not ruled out that the fine-tuned text branch is simply noisier. The ablation is what would decide it.
