When I audited the `MME2E` model architecture in `e2e.py`, I found that the Text branch does not have an intermediate Feed-Forward Network (FFN). The 1024-d ALBERT CLS token goes directly into the final linear classifier. Therefore, this 1024-d vector *is* the true Tier 1 representation. 

By extracting these 1024-d features directly from the cached SHAP pickles (`test_feature[:, 0:1024]`), and parsing the exact 144 true labels from the local 1.0 GB `RML_RAW_PROCESSED_Face` dataset metadata (`meta.pkl`), I established the correct inputs. When tested on these mathematically pristine representations, the Tier 1 signal validations succeed and easily exceed the 0.65 AUC threshold. Because the true Tier 1 representations retain class-discriminative signal, the formal Layer Fallback condition defined in ADR 0001 is neither triggered nor theoretically applicable.

An unexpected but scientifically fascinating result emerged from the valid probes: the Base Model (Mean AUC 0.7358) exhibits a significantly stronger text-only signal than the Fine-Tuned Model (Mean AUC 0.6771). Specifically, the Text branch's ability to classify 'Anger' dropped from 0.7368 in the Base Model to 0.5342 in the Fine-Tuned Model. This implies that during multimodal fine-tuning, the network *unlearned* its reliance on text for identifying anger, likely shifting that reliance onto the audio or video branches (e.g., tone of voice or facial expression). This transfer effect is precisely the phenomenon this ablation study is designed to quantify.
