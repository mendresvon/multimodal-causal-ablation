## 4. Empirical Findings & Data Links
The audit identified 7 remaining critical/high issues. The full report is saved to `comprehensive_audit_report.md` at the repository root. Key findings:

1. **(CRITICAL) SHAP aggregation formula bias.** Cell 10 computes `|sum(SHAP)|` per modality — signed values cancel before the absolute value, biasing toward low-dimensional modalities (Audio 64-d). The docstring claims "Sum |SHAP| within modality" but the code does the opposite. After discussion, the correct fix is `mean(|SHAP|)` per modality (`np.mean(np.abs(sv[:, start:end]), axis=1)`), which normalizes by dimensionality and removes both the signed-cancellation bias (`|sum|`) and the dimension-count bias (`sum(|.|)`). All three metrics — `mean(|phi|)`, `sum(|phi|)`, and `|sum(phi)|` — should be reported in VI-D for transparency.

2. **(CRITICAL) Ablation evaluated on only 144 test samples** (~24 per class). Minimum detectable effect = 4.17% (1 sample flip). The experiment is severely underpowered.

3. **(HIGH) Transfer Retention Ratio R = 0/0 for all 6 classes.** The code forces R = 0.0 when base_drop = 0.0, which mechanically triggers "Substrate Dispersion." This is a mathematical artifact, not a finding.

4. **(HIGH) Cosine similarity (0.71–0.98, "High Sharpening") contradicts ablation transfer ("Substrate Dispersion").** The protocol says Day 14 should override Day 13, but the Day 14 result is vacuous (0/0 ratios).

5. **(HIGH) No dose-response control.** Without k=32, k=64, or full-modality knockout, the "multimodal redundancy" interpretation is indistinguishable from "wrong modality" or "insufficient power."

6. **(HIGH) Probe-fit data leakage.** L1 probes fitted on all 720 samples; ablation evaluated on a 144-sample subset of those same 720 samples. Neuron rankings are optimistically biased.

7. **12 of 16 original master audit issues are confirmed fixed.** The L1 probe weight ranking, Pipeline-based scaling, Day 13 cosine similarity, Phase D all-class evaluation, and deterministic seed policy are all correctly implemented.

## 6. Interpretability Retrospective
The most important takeaway from this audit is that the SHAP aggregation formula question is not a simple "fix the code" problem — it's a methodological design decision with no single correct answer. `|sum(phi)|` measures directional push, `sum(|phi|)` measures total feature importance, and `mean(|phi|)` measures average per-feature importance. Each answers a different question, and the dominant modality verdict may change depending on which one you use. The honest scientific approach is to compute all three, report all three, and anchor the modality selection on the dimension-invariant metric (`mean(|phi|)`). If that metric still selects Audio, the current experiment stands on solid ground. If it selects Text, the experiment needs to re-target the Text branch.

The near-zero ablation drops remain scientifically interesting regardless — they reveal that the MME2E architecture's multimodal fusion creates sufficient redundancy that sparse neuron ablation cannot flip predictions. But this interpretation requires a dose-response control (ablating progressively more neurons) and a full-modality knockout to be credible. Without those controls, a reviewer can dismiss the null result as an artifact of insufficient power or wrong-modality targeting.
