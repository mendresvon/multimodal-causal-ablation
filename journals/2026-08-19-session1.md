## 5. Roadblocks, Failure Modes & Debugging Log

The notebook diff was the only thing in this session that could have caused real damage, and it came very close to being read backwards.

`git status` showed `multimodal-causal-ablation-v3.ipynb` as modified, with `1 insertion(+), 3479 deletions(-)`. A deletion of 3479 lines against a single insertion is what a destroyed file looks like, and my first reading was that something had stripped the notebook. That reading was wrong, and so was the correction I nearly made on the strength of it.

Parsing both versions as JSON showed 33 cells in each, 16 with outputs in each, and identical `source` in all 33. Comparing serialized output sizes cell by cell showed the working-tree version was *larger*: 403,876 bytes of outputs against the committed version's 393,246, plus a 126,792-byte `metadata.widgets` blob that the committed version does not have. Nothing had been stripped. The working tree held a fresh Colab re-run of the same code, and the line count collapsed because Colab writes the notebook as a single line, `wc -l` returns 0 for the working-tree file and 3479 for the committed one. The entire diff was one JSON object reflowed onto one line.

So the file was not damaged, and the honest question became which version belongs in a frozen archive. I kept the committed one, for three reasons. The re-run's only additional content is PyTorch deprecation warnings and tqdm progress-bar widget state, so nothing of substance is lost. The committed version has one provenance line the re-run does not, `Removed 1441 AppleDouble sidecar files left by a previous run`, which is the trace of the sidecar halt that 2026-08-12 session 1 diagnosed. And the committed version is the run that the README, the journals, and `results/` all describe; the re-run is an undated execution that no entry documents. The fidelity gate printed identically in both (76.39% and 79.86%), which is the check that mattered before I decided. I saved the re-run outside the repository before overwriting it rather than discarding it outright.

The lesson I want on the record is that a diff statistic is not a measurement of a notebook. `1 insertion, 3479 deletions` and `3479 insertions, 1 deletion` describe the same reformatting from opposite ends, and only one of them looks alarming. Parsing the file answered in one step what the diff had made ambiguous.

The branch divergence had the same shape. `24 25` reads as two branches that have drifted apart and would need a merge or a rebase to reconcile, and I said as much before checking. Comparing the tree objects took one command and showed there was nothing to reconcile at all. In both cases the number that looked like a problem was a summary statistic standing in for content I had not looked at yet.

## 6. Interpretability Retrospective

The thing I keep coming back to is that the most valuable document in this repository was untracked. `docs/section-vi-d-professor-briefing.md` is the only place where the tables, the claims ladder, and the reasoning behind every methodological choice sit together in one narrative, and it is cited by path and line number from the FACS spec. It existed only in the working directory of a Google Drive mount, the same mount that already destroyed four commits on 2026-08-11. It survived by luck.

That is a failure of the journaling protocol rather than of the writing. The protocol is careful about results artifacts and silent about prose written for a meeting, and prose written for a meeting is exactly the kind of file that gets produced in a hurry and never staged. The successor repository's project rules file now makes the boot-reading order explicit and puts the equivalent documents in it, which forces them to be tracked because a cold session is told to read them.

On the science: what closes here is a clean negative result that a reviewer can trust, which is not the same as a result that helps the paper. Tables VII and VIII show that the selected coordinates are causally class-selective. Table IX shows that this does not transfer across training lineages. The professor's objection is that the second sentence, stated as a null, does not tell a reader anything they can use. Reframing the question from "do these coordinates survive fine-tuning" to "do these coordinates mean anything physiological" keeps the validated part and drops the part with nothing to say. I did not see that until he said it.
