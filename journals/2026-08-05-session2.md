## 5. Roadblocks, Failure Modes & Debugging Log
Tracing the proxy inference loop in `ablate_and_evaluate` turned up an evaluation flaw. The function computes accuracy over whatever `labels` tensor it is handed, and the calling code passed `labels_tier1` alongside the full 720-sample feature tensor.

The dataset concatenates the splits linearly: Train (518) + Val (58) + Test (144). Passing all 720 samples into the evaluation loop meant the reported drop was dominated by the **training set**. The network has memorized those samples, so mean-ablating 5 neurons does not move the logits far enough to flip the argmax. Whatever effect exists in the 144 test samples was averaged away by 576 samples that cannot move.

## 6. Interpretability Retrospective
Ablations scored on the training distribution measure the wrong thing. Memorized samples hold their predictions under intervention, so including them answers "can the model still recall this example" rather than "is this neuron necessary." I read the flat result as evidence that Audio was causally inert, which it was not, the measurement had no room to show an effect. The split boundary should be enforced at the function signature, not left to the caller.
